auto

Reads, searches, edits and commands inside the workspace. Reads outside it too — it is your assistant and those are your files.

confirm

Recursive deletes, force-push, sudo, writing /etc or the shell profile, reading .ssh or .env, piping the internet into a shell, a program run through a read-only tool's flag. Unattended, these are refused.

s allows that rule for the rest of the session: rm -rf build once and recursive deletes stop asking, but a force-push still asks.

deny, even if you say yes

Deleting / or your home directory, writing a block device, formatting a filesystem, shutting the machine down, a fork bomb.

Saying allow trusts it with your files. It does not trust it with the disk.

On your machine, natively — no container. The gate is the whole boundary, a deliberate trade: a sandbox would keep it from the files a personal assistant exists to read. noesis --doctor says which one you are in.

What it does

03. It remembers

What you told it, what worked, how you like things done.

Across sessions, in a local SQLite file you can open. A runbook it reads becomes a skill it loads next time the same kind of work comes up.

04. It can be left alone

Queue tasks, schedule them with cron, point it at a mailbox.

Default deny: it answers only senders you list. State is written after every step, so it survives being killed mid-task and resumes from where it was.

05. It runs where you are

Python 3.12+. Any OpenAI-compatible endpoint, or Anthropic.

NVIDIA's free tier is the default. noesis --doctor checks every precondition, prints one line per item, and changes nothing.
